# Style guide: Swedish medical multiple-choice translations

The English source is authoritative for meaning. The Swedish text must ask the same question, with the same answer options, in natural Swedish medical language. A rendering that follows the rules below is **correct** and must not be flagged or changed.

## 1. Terminology
- **Drug names use Swedish INN spelling** (as in FASS and the national product register NPL): `vankomycin`, `aciklovir`, `azitromycin`, `vinkristin`, `alteplas`, `hydroxikarbamid`, `ganciklovir`. English spellings (`vancomycin`, `acyclovir`, `alteplase`) are errors in Swedish text.
- **Established Swedish clinical terms are preferred over calques of the English term.** These are correct and must be kept:

  | Swedish term | English term |
  |---|---|
  | `resistens` | mass |
  | `halsvenstas` | jugular venous distension |
  | `egentlig depression` | major depression |
  | `metabol acidos` | metabolic acidosis |
  | `släppömhet` | rebound tenderness |
  | `trumpinnefingrar` | digital clubbing |
  | `intrinsic factor` | intrinsic factor |
  | `kongestiv hjärtsvikt` | congestive heart failure |
  | `färskfrusen plasma` | fresh frozen plasma |
  | `djup ventrombos` | deep vein thrombosis |
  | `alkaliskt fosfatas` | alkaline phosphatase |
  | `ytligt om` / `djupt om` | superficial to / deep to (anatomical position) |
- **Protected terms.** The following established Swedish clinical terms are correct. They must never be reported as errors or replaced, even when they are not a word-for-word translation of the English (inflected forms included):

  | Swedish term (protected) | English term |
  |---|---|
  | `hereditet` | heredity, family history (of a disease) |
  | `persisterande ductus arteriosus` | patent ductus arteriosus |
  | `lungröntgen` | chest X-ray |
  | `påverkad` / `opåverkad` | in acute distress / in no acute distress (general condition) |
  | `medtagen` | ill-appearing, exhausted |
  | `reposition` | reduction (of a fracture or dislocation) |
  | `resistens` | (palpable) mass |
  | `ledspringa` | joint space |
  | `preparationsgräns` | finish line (dental preparation margin) |
  | `vidmakthållande` | maintenance (treatment phase) |
  | `Blockmönster`, `Sifferrepetition` | Block Design, Digit Span (Wechsler subtests) |
  | `exspektans` | expectant management, watchful waiting |
  | `utsättande` | discontinuation (of a drug) |
  | `femurkomponent` | femoral component |
  | `S-albumin` | serum albumin |
  | `dunkömhet` | tenderness to percussion |
  | `blåsljud` | (heart) murmur |
  | `lambå` | flap (surgical) |
  | `exartikulation` | disarticulation |
  | `sjok` | sheets (of cells) |
  | `skelettsmärta` | bone pain |
  | `andfåddhet` | shortness of breath |
  | `akillessenan` | the Achilles tendon |
  | `ljusstela pupiller` | non-reactive (fixed) pupils |
  | `fibrös dysplasi` | fibrous dysplasia |
  | `myoton dystrofi` | myotonic dystrophy |
  | `stomi` / `stomin` | stoma, ostomy |
  | `tenesmer` | tenesmus |
  | `elaxel` | electrical axis (ECG) |
  | `oöm` | non-tender |
- **Frequently mis-flagged, but correct:** `status` is neuter (`ett status`, `statuset`, `neurologiskt status`); `graft` is neuter (`ett graft`, `graftet`); `Students t-test` is the Swedish eponym form (no apostrophe).
- **A Swedish term is not wrong because another Swedish term exists, or because it is not a word-for-word translation.** A more literal or English-like rendering is not better.
- **Latin and international terms are normal Swedish medical language**: `sternum`, `uterus`, `bilateral`, `postpartum`, `isthmus`, `ovarium`, `a. carotis interna`, `processus styloideus`, `in situ`. Do not replace them with Swedish paraphrases, and do not treat them as English.
- **Abbreviations:** keep those in Swedish clinical use (EKG, CT, MR, EEG, CRP, HbA1c, ADHD, KOL, CSV, GI, IV, BMI). Use the Swedish form where one exists (KOL for COPD, CSV for CSF, EKG for ECG). Do not expand an abbreviation unless the source expands it.
- **Eponyms** keep the person's name (`Wilms tumör`, `Münchausens syndrom`, `Students t-test`).
- **Proper names** of trials, scales, organisations and genes stay as in the source. Acronyms and trial names stay as in the source, especially when the question asks what they stand for.
- A term that is **genuinely English** where a standard Swedish term exists is an error. Examples: ordinary words (`and`, `laptop`), or phrases left untranslated (`Hungry bone syndrome`, `confounders`).

## 2. Numbers and units
- **Decimal comma** in measurements: `38,4 °C`, `1,5 mg`, `7,2 mmol/l`.
- **Thousands:** a space for 5+ digit numbers (`21 000`); 4-digit numbers may be written without a separator (`1200`).
- **Keep every number and unit of the source.** If the source gives two units, keep both (`99,5 °F (37,5 °C)`). Never convert or round.
- **Numbers written as words** (`tre dagar`, `vartannat år`) are correct when the value is unchanged.
- **Keep codes, chemical names, p-values and lists exactly as in the source**: `E11.9`, `2,3-BPG`, `p < 0.05`, `1,2,3 & 4`.

## 3. Exam language
- **Fixed phrases of Swedish medical exams are correct**: `Vilket av följande …`, `Vilket är det mest lämpliga nästa steget …`, `anamnes på`, `på rumsluft`, `i serum`, `söker på grund av`, `Vid undersökning …`.
- **Answer options must stay parallel** with each other in form (definiteness, length, structure), as in the source.
- **Do not add, remove or reorder information.** Negation, laterality, quantity, timing, severity and certainty must be preserved exactly.

## 4. Faithfulness
- **Preserve source ambiguity** where possible. Do not correct the English source medically. If the English source itself is wrong or garbled, that is a *source issue*, not a translation error.
- **Prefer no change over a speculative change.** A different but equally correct wording is not an error.
